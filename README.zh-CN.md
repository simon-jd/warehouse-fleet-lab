# 仓库多机器人调度与导航评测

本项目实现项目规格的首版：C++20 离散模拟器、取货→送货任务、三种任务分配策略、时空 A*、预留表、故障注入、独立碰撞校验和固定种子评测。

它主要补充 C++ 算法、共享资源冲突处理、可靠性和实验设计能力。规划核心单线程，机器人动作按离散时间步同步执行；评测器通过有上限的独立子进程运行实验。不能据此宣称分布式调度服务、真机导航或生产部署。

构建与复现命令见 [英文 README](README.md)。正式评测冻结三张地图、10/30/50 台机器人、10 个种子，共三种方法 270 次，加 lambda=0 消融 90 次；同时记录未完成任务，避免只看成功任务造成偏差。拥堵感知并非所有场景都更好，完整结果和负结果见 [评测报告](docs/evaluation.md)。

已修复并可复现的核心问题是：机器人提前经过目标点时，不能在预留终点到达前完成服务，否则会破坏其他机器人的未来预留。[失败分析](docs/failure-analysis.md)给出了复现命令、修复和故障演示的证据。

ROS 2 Jazzy/Gazebo Harmonic 执行层仍是第二阶段，尚未实现或验证。没有真实机器人、云端生产运行、硬件安全认证或 ML 训练/推理结果。此次实现使用了编码代理协助。
