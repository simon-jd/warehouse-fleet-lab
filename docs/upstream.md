# Upstream and compatibility review

Checked 2026-09-06 PDT (2026-09-07 UTC). Official GitHub REST metadata was read in addition to linked release notes; no third-party summaries inform dependency decisions. No upstream implementation is vendored in the C++ core. The SIL layer generates robot/world/configuration artifacts from the installed official Nav2 TurtleBot models; those retain upstream ownership and licensing. Hungarian assignment, grid BFS, time-expanded A* and experiment tooling are implemented in this repository; no originality claim is made about these established algorithms.

[ROS REP-2000](https://www.ros.org/reps/rep-2000.html) documents Jazzy's May 2024–May 2029 support. [Gazebo's official ROS compatibility guide](https://gazebosim.org/docs/harmonic/ros_installation/) pairs Jazzy with Harmonic. [Nav2 Iron→Jazzy migration](https://docs.nav2.org/rolling/configuration_and_development/migration_guides/iron/Iron/) includes BehaviorTree.CPP 4.5 XML/source changes and stamped velocity options: real adapters need migration tests, not a version-string edit. The new adapter uses the qualified Jazzy configuration and Twist boundary; it does not claim an Iron migration or stamped-command upgrade. Runtime versions and actual execution are recorded in [SIL qualification](sil-validation.md).

Fresh apt metadata was also checked during SIL development: the pinned Nav2 1.3.12 Debian packages remain the installed and candidate versions in the official Noble ROS repository. A newer GitHub release therefore does not imply a newer qualified binary package. Derived simulation artifacts carry [upstream attribution and Apache license text](../third_party/NOTICE.md).
